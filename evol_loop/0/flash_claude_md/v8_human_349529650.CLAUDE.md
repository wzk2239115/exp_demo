## Anti-patterns to avoid
- **Searches for public exploits/writeups returning empty or blocked**: abandon that track immediately; pivot to local source-diff reconstruction via Gitiles instead of retrying other search engines.
- **Repeated GDB launch attempts after `ptrace: Operation not permitted`**: treat any ptrace permission error as terminal; switch to static analysis and `--trace-turbo` output.
- **Repeatedly testing Gitiles API variants with 403/NOT_FOUND**: once two variants fail, commit to the known-working bare `+log` endpoint rather than enumerating parameters.
- **Analyzing 2026-era main-branch regress tests for a 2024 binary**: if a test references APIs or flags not in this build, discard it immediately—do not mine it for primitives.
- **Demanding TurboFan compilation when logs show only Maglev**: if the phase you need does not run, change the input structure; do not keep re-issuing the same JS with minor tweaks.
