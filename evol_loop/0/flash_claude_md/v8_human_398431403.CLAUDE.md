- **Re-checking non-existent `/flag`**: confirmed absent early; do not re-test it; focus on remote behavior via the server.
- **Re-testing many structural variants (element counts, callbacks) after one variant clearly works**: once a minimal crashing input is found, use it for diagnostics instead of expanding the matrix.
