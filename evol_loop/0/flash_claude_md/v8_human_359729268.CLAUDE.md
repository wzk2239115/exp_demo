- **Spending a long time on disassembly extraction from code logs**: the log often has only the header line and no body. Detect the empty body early and move to graph/behavior analysis rather than trying other extraction methods.
- **Trying to identify the V8 version from a source tree without git**: no `.git`, no REVISION file means version discovery is a dead end. Skip it and work directly from the source code text.
