## Anti-patterns to avoid
- **Repeatedly retrying GDB after a ptrace denial**: switch to static analysis or other debugging approaches immediately.
- **Testing `%DebugPrint` on the remote server after confirming it's unavailable**: use local builds or crash-dump analysis instead.
- **Spending many steps on Wasm opcode encoding errors without checking the local builder's helper functions first**: read the builder source before writing bytes by hand.
- **Treating a leaked constant value as a variable to tune**: if changing a parameter (e.g., P) does not change the output, it's a fixed offset; stop parameter sweeping and reformulate the primitive.
- **Starting a new source search without reading the already-downloaded file referenced in your notes**: open the file before spawning another Grep.

## Missed signals
- If you find you've leaked a Map object, act on it as a potential fake-object header before building further primitives.
- If you confirm an RWX region exists, immediately evaluate a shellcode-injection path rather than continuing to optimize the current primitive.
- If you leak a JSArray address, consider using it as a base for fake objects before pursuing other read/write strategies.
