## Anti-patterns to avoid
- **Search engine / bug tracker queries return empty or blocked**: stop retrying external lookups; switch to fetching source from googlesource or analyzing local files.
- **Re-reading the same source function (e.g., `NewWasmTypeInfo`, `struct.set`) multiple times with identical conclusions**: when a code path yields no new insight on the second read, abandon it rather than revisiting.
- **Chasing commit/CL metadata (API formats, pagination) consumes many steps**: if the exact hash/log isn't found after two tries, work from the patch diff already fetched instead.
- **GDB batch-mode `finish` hangs and produces no output**: if a debugger command spins, kill it and use `-ex` with explicit breakpoints, or skip GDB entirely.
- **Serial web fetches while waiting on network**: launch downloads in the background and continue source analysis concurrently.
