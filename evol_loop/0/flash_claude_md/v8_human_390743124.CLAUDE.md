## Anti-patterns to avoid
- **TrustSpace/TrustedPointer source analysis spiral**: when you confirm `V8_ENABLE_SANDBOX` absent, stop re-deriving that there's no TrustedSpace; switch the analysis target.
- **Re-running variants of a PoC that already returned EXIT 0 locally and on the server**: after the second non-crash, drop that primitive and seek a different one.
- **Repeatedly fetching external issue/commit pages that fail with auth/rate-limit** (SPA, 401, API limit): if a fetch fails twice with those errors, stop and work from the local git/source only.
- **Waiting idle on a long compile**: if a debug build is still running after ~10 min, do parallel work instead of polling; guard against session truncation.
- **Treating a server "no output" as a crash**: a busy-loop script that produces nothing for ~0.5s is killed by an output-idle timeout. Verify with periodic prints before concluding a crash.

## Missed signals
- If a gitiles branch log reveals a suspicious fix commit, fetch its diff immediately and focus on constructing a PoC, not on more static analysis of that area.
- If a regression test file exists in the source and matches a reference PoC, use it to quickly classify the bug's preconditions (e.g., sandbox-only) early.
- If an external report mentions a commercial exploit vendor, treat that bug as high-value; prioritize reproduction over reading surrounding code.
