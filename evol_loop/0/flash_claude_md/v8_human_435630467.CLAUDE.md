## Anti-patterns to avoid
- **Repeatedly retrying gitiles pagination/URL formats after identical failures**: if a fetch pattern fails twice with the same error, switch technique (e.g., use the GitHub API blob endpoint, or a local git history via `git log` after a shallow clone) before retrying a third time.
- **Broad scanning of commit lists yielding overlapping candidates**: if a new search result set looks like a large superset of the previous scan, stop scanning and pick the top 2–3 distinct items for deep dive instead of re-filtering keywords again.
- **Reading regression-test titles only and discarding candidates based on names**: if a candidate file matches the general bug area you seek, open the full test file and try to run/adapt it locally before judging it a dead end. Titling is unreliable.
- **Spending time on "gadget" bugs that require an existing primitive**: if the fix or test requires a pre-existing addrof/write primitive to exercise, mark it as non-primary and move on; do not build a chain around it first.
- **Assuming a fixed function exists in the specific base commit**: before analyzing a diff, verify the exact function/optimization entry point exists in the local source tree (grep for the symbol), else you may be chasing a phantom difference.

## Missed signals
- If you find a candidate that is **enabled by default** (e.g., a compiler optimization not gated by a flag) and is reachable with no special global APIs, prioritize local reproduction immediately over further source-diff analysis.
- If you have verified a bug that gives a concrete OOB/type-confusion read or write in a local test, do not leave it mid-analysis to explore other candidates; the run stalled exactly at that point.
- When a local test confirms a bug triggers a crash or unexpected output, stop reading more commit history and iterate the PoC further with `console.log` instrumentation to map bounds.

## Environment notes
- The previous run used a background task (with `timeout`) to fetch commit lists in bulk; persisting the JSON to disk worked, but subsequent pagination attempts via an index/`start` parameter did not advance pages — treat pagination as unreliable and prefer full-list fetches per commit.
- Local test scripts: since `load` is unavailable, concat multiple script sections into a single `.js` file and run the whole file to keep the execution context continuous.
