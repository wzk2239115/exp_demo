## Anti-patterns to avoid
- **Repeated broad CVE/grep.app/GitHub API searches hitting rate limits or 404s**: stop after 2-3 failures; switch to local source analysis.
- **Multiple GDB attempts failing with ptrace denied**: if the first ptrace attempt errors out, don't retry; plan without debugger.
- **Iterating >10 times on the same dedup test by tweaking fill markers or indices**: if three consecutive variations all fail the same runtime check, abandon that hypothesis and inspect the check's source directly.
- **Launching a subagent with a vague "search for exploit" mandate**: only delegate concrete diffs or function-specific questions; generic web searches yield nothing.
- **Re-reading the same source files repeatedly after a failed test**: if a probe contradicts theory, first verify the test's byte encoding and runtime flags, then question the theory—not the other way around.
