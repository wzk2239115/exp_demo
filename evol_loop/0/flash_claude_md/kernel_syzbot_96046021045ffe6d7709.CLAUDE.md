## Anti-patterns to avoid
- **Wget/curl failing in VM**: check for python3's urllib immediately instead of trying each cli downloader.
- **Repeatedly fixing VM output capture (0.5s reads getting truncated/polluted)**: switch to file-redirect or longer reads rather than tweaking pty scripts again.
- **HTTP server won't stay up**: prefer python3 -m http.server with nohup+disown on a chosen port, then verify via ss before proceeding.
- **gdbstub hangs when booting with -S**: don't freeze the CPU for inspecting state; boot without -S and attach later.
- **Re-testing file transfer after a working method exists**: trust the established upload path and move forward; re-checking server status wastes turns.
- **Getting stuck in compile hell**: pre-test `gcc -B /usr/bin` works before deeper attempts; also test in a minimal hello-world before your actual program.
